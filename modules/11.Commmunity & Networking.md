# SKILLY — Module 11: Community & Networking

## 1. Module Overview

**Module Name:** Community & Networking

**Purpose:**  
The Community & Networking module provides a space for students and other approved SKILLY users to interact, share knowledge, build professional connections and participate in peer activities.

## 17. Module Boundary

### Included

- Community dashboard
- User discovery
- Networking
- Connections
- Peer interaction
- Knowledge sharing
- Resources
- Peer skill exchange
- Discussions
- Events / activities
- Community contributions
- Notifications

### Not Included in This Module

- Student profile management
- Core mentorship management
- Internship application management
- Placement management
- Company recruitment management
- Core authentication implementation
- Detailed AI implementation
- Detailed database schema
- Detailed API specification

These functions belong to their respective modules.
