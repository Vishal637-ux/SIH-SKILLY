# SKILLY — Module 03: Student

## 1. Module Overview

**Module Name:** Student

**Purpose:**  
The Student module is the main student-facing area of SKILLY. It supports the student's skill development, career planning, opportunities, practical exposure, mentorship, portfolio and placement journey.

### Core Student Journey

```text
Student
   ↓
Profile
   ↓
Skill Assessment
   ↓
Skill Profile
   ↓
Skill Gap
   ↓
Career Roadmap
   ↓
Learning / Skill Development
   ↓
Internship / Project
   ↓
Mentorship
   ↓
Placement
   ↓
Career Growth
```

## 3. Student Dashboard

The dashboard provides a centralized view of the student's current career journey.

### High-Level Information

- Profile progress
- Skill development progress
- Skill gaps
- Recommended opportunities
- Applications
- Internship/project progress
- Achievements
- Notifications
- Career journey status

---

## 4. Student Profile

The student maintains their basic academic and career information.

### Profile Areas

- Personal information
- Academic information
- Institution
- Department
- Skills
- Certifications
- Projects
- Internship experience
- Achievements
- Career interests

The profile becomes the base for skill mapping, recommendations and opportunity matching.

---

## 5. Skill Assessment

The student can assess their current skills through the platform.

### Flow

```text
Student
   ↓
Assessment
   ↓
Assessment Result
   ↓
Skill Profile
```

The assessment helps identify the student's current skill level.

---

## 6. Skill Profile

The student's skills are represented in a structured profile.

### Purpose

- Understand current skills
- Maintain skill information
- Connect skills with career roles
- Support opportunity matching
- Track skill development

---

## 7. Skill Gap

The system identifies the difference between the student's current skills and the skills required for a selected career role or opportunity.

### Flow

```text
Current Skills
      +
Required Skills
      ↓
Skill Gap
      ↓
Skills to Improve
```

The result helps the student understand what needs improvement.

---

## 9. Career Roadmap

### Flow

## 22. Module Boundary

### Included

- Student dashboard
- Student profile
- Skill assessment entry
- Skill profile
- Skill gap
- Career exploration
- Career roadmap
- Learning / skill development
- Internship and project discovery
- Applications
- Mentorship
- Portfolio
- Resume
- Achievements
- Community
- Competitions
- AI career support
- Notifications
- Career journey tracking

### Not Included in This Module

- College / TPO administration
- Industry/company administration
- Teacher / trainer administration
- Alumni / mentor administration
- Core authentication implementation
- Detailed AI model implementation
- Detailed database design
- Backend API specification

These belong to their respective modules or technical specifications.
