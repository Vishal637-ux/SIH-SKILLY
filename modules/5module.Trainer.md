# SKILLY — Module 05: Teacher / Trainer

## 1. Module Overview

**Module Name:** Teacher / Trainer

**Purpose:**  
The Teacher / Trainer module supports teachers, faculty and trainers in student skill development, training, mentorship, industry interaction and knowledge-sharing activities.

---

## 18. Module Boundary

### Included

- Teacher / trainer dashboard
- Professional profile
- Student connect
- Skill and training activities
- Training programs
- Mentorship
- Industry connect
- Workshops / FDPs
- Projects and practical learning
- Student progress
- Achievements and recognition
- Resources and knowledge sharing
- Scheduling
- Notifications

### Not Included in This Module

- Student personal dashboard
- College / TPO administration
- Industry/company administration
- Alumni / mentor administration
- Core authentication implementation
- Detailed AI implementation
- Detailed database schema
- Detailed API specification

These functions belong to their respective modules or technical specifications.
